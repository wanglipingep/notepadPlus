# NotepadPlus 版本更新记录

这里记录 NotepadPlus 每个正式版本的功能变化、体验优化和重要修复。

## 2.9.5（2026-11-13）

### 个性化签名

- 修复「新增签名」无效：旧版字符串数组存储每次读取都会换新 UUID，导致列表与输入框身份错乱；改为带稳定 id 的对象列表并自动迁移。
- 签名管理改为独立页面：左侧卡片列表（搜索、序号、摘要、字数），右侧多行编辑器，支持新增、删除、上移/下移与右键排序。
- 偏好设置改为可拖动、可缩放的浮动面板（标题栏拖动，右下角缩放），便于管理较多语录时放大编辑区。
- 内置默认语录改为作者维护的完整合集；标题栏展示改为「整条播完再下一条」——横向滚动从头到尾读完整段、百叶窗按行（长文自动断句）翻页，并新增打字机逐字模式（默认）。
- 打字机不缩小字体：一行铺满后从左侧重新起行继续剩余文字，不再横向挤出视口。
- 语录固定显示在窗口标题栏，并与「文档导航」右缘对齐，避免侧栏上空档或标题栏大块留白；支持语录 JSON 导入/导出（追加或替换，不丢已保存条目）。

### 发布记录

- 2026-11-13：升级至 2.9.5（Build 26），提供 Apple 芯片与 Intel Mac 通用的 Universal DMG，可拖入“应用程序”安装。

## 2.9.4（2026-11-10）

### 体验与修复

- 修复大文件 Markdown 预览拖动滚动条时被 progress 吸附顶/底、与编辑器互相抢滚动的问题。
- 修复外部文件变化提示中「重新载入」因 Alert 绑定被提前清空而无效的问题。
- 收紧文档导航列表行距，便于一屏查看更多文档。
- 文档标签栏默认滚到右侧末尾，打开/新增标签后更方便操作。
- 修复自动换行时空行点击光标落到相邻内容行的问题（如大模型聊天记录）。

## 2.9.0（2026-11-07）

### 搜索文件（Raycast 风格）

- 默认「整台 Mac」全盘 Spotlight 检索，去掉「授权…」摩擦入口；范围可切换个人文件夹／最近文件。
- 空格多词 AND、类型词（pdf／excel／word／ppt／txt／md／image／zip 等）与客户端模糊排序；右侧 QuickLook／ImageIO 缩略图预览与元数据。
- 性能：先搜个人文件夹再补全盘、凑够结果或超时即终止 `mdfind`、扩展名谓词、短防抖；浮动面板可拖动缩放，并修复拖动残影。

### 系统级代码片段

- 对齐 Raycast Snippets：⌥⌘S（或菜单／工具栏）唤出面板，回车将展开后的内容粘贴回**打开面板前**所在应用的光标处（剪贴板 + ⌘V 注入）；在 NotepadPlus 内则直接插入编辑器。
- 首次使用可引导打开「辅助功能」设置；菜单「辅助工具」与工具栏提供搜索／新建片段、剪贴板历史、搜索文件入口。

### 发布记录

## 2.8.0（2026-11-07）

### 外部文件变化重载

- 修复沙盒下因未开启 Security-Scoped 访问而导致签名读取失败、无法提示重载的问题。
- 多文档变更改为队列提示，避免一条 alert 挡住后续文件。
- 自身保存／自动保存后短暂抑制变更检测，减少误报。
- 提示框中的“重新载入”与右键“从磁盘重新载入”走同一路径；取消待写入的自动保存，并强制刷新编辑器缓冲，避免旧内容盖住磁盘改动。
- 重新载入路径与手动重载对齐（授权、会话、错误恢复），并尽量保持当前视口。

### 切换标签后首次点击

- 标签恢复后增加短时交互保护，并在点击前预布局可见行，避免首次点击落到文末。

### 查找定位

- 上下切换匹配项时，当前匹配使用橙色高亮，并强制滚入可见区域。

### 辅助工具

- 新增“辅助工具”菜单：搜索文件（Raycast 风格文件名检索＋预览／元数据）、代码片段（搜索／新建双界面，时间分组、元数据、动态占位符）、以及剪贴板历史（监听系统剪贴板、固定／筛选／插入编辑器，⌘⇧V）。

### 大文件性能策略

- 对齐 Notepad++：超大文档关闭自动换行、语法高亮、括号匹配与折叠扫描，优先保证打开与编辑响应。

### 函数列表与多选区

- 底部面板新增函数列表，支持 Swift／Python／JavaScript／TypeScript／C 系等符号跳转与筛选。
- 新增“选择下一个匹配项”（⌘⌃D）：可对多个相同选区同时键入、删除、剪切、复制与粘贴。

### 代码折叠

- 在 JSON 折叠之外，为 Swift／Objective-C／C／C++／JavaScript／TypeScript／CSS 等提供大括号折叠。

### 发布记录

- 2026-11-07：升级至 2.8.0（Build 20）。

## 2.7（2026-11-05）

### Markdown 预览

- 预览文字支持选择和复制，新增“复制预览”按钮：有选区时复制选中文字，没有选区时复制全部渲染后的正文。
- 源码与预览双向同步滚动，切换全文预览后返回编辑时保留对应位置；按 Markdown 块与源码行映射，长段落、表格和代码块采用近似定位。
- 编辑内容实时刷新预览，原地更新正文和主题，避免每次输入后跳回顶部。

### 快捷键与多层分组

- 查找和替换输入框支持 ⌘V 粘贴，剪切、复制、粘贴与全选跟随当前键盘焦点；避免多窗口重复执行粘贴命令。
- “我的分组”支持多层级，点击分组右侧“…”中的“新建分组…”，自动以该分组作为上级，创建弹框显示完整父级路径。
- 支持调整上级分组，并阻止移入自身或后代；删除分组时将其直属文档及子分组提升到原上级，保留全部内容。
- 会话与未保存文档恢复记录保存分组层级，兼容旧版顶级分组；继续保留 2.6.1 的文件访问恢复和会话备份保护。

### 发布记录

- 2026-11-05：升级至 2.7（Build 18），提供 Apple 芯片与 Intel Mac 通用的 Universal DMG，可拖入“应用程序”安装。

## 2.6.1（2026-10-27）

### 升级后的分组与文件访问修复

- 文件授权失效、外置磁盘未连接或文件暂时不可读时，保留原标签、分组关系、固定状态及行书签；显示访问恢复入口，避免启动时静默移除文件记录。
- 支持重新选择原文件，或授权包含原文件的文件夹；重新载入时沿用原文档与分组，一次文件夹授权可恢复该目录下多个不可访问的文档。
- 保留已有安全书签，生成新书签失败时不再用空值覆盖；文档打开期间保持安全访问，关闭时释放，并在读取会话前恢复工作区与文件夹授权。
- 分组与会话增加独立原子文件、上一版本备份和首次迁移原始副本；读取损坏数据时保留原始字节并尝试备份，全部读取失败时停止覆盖原会话。
- 兼容旧会话中缺失的可选字段及未知的语言、编码、换行和分组颜色值，避免单个显示选项导致整个会话恢复失败。
- 未载入的文件禁止保存，防止恢复占位内容覆盖磁盘文件。

### 安装包与恢复说明

- 打包时保留已有应用签名，支持指定 Developer ID 身份签名，避免将正式签名强制改为临时签名。
- 当前本地 DMG 仍使用临时签名，未进行 Developer ID 公证；跨版本后 macOS 仍可能要求重新选择文件或文件夹授权。
- 已被旧版覆盖且没有备份的分组无法凭空重建；请保留原应用数据与系统备份，勿卸载清理数据。
- 2026-10-27：升级至 2.6.1（Build 17）。

## 2.6（2026-10-26）

### 查找与替换

- 参考 Notepad++ 的操作方式，完善普通、扩展和正则表达式三种搜索模式，支持行首行尾、点号匹配换行和捕获组替换。
- 支持将编辑器选中的原文直接填入替换框，自动处理美元符号和反斜杠转义；可将查找、计数、标记、查找全部和替换限定在指定选区。
- 单次替换先定位匹配项，再替换并跳至下一项；保留查找条件和循环选项，关闭循环时在文档边界停止。
- 单次及批量替换接入编辑器撤销／重做，并修复捕获组上下文、零长度匹配和替换结果计数问题。

### 标题栏、语录与外观

- 标题栏只保留语录，移除重复的 NotepadPlus 名称和侧栏占位，使语录靠近窗口控制按钮。
- 语录区域跟随所属窗口的实际尺寸调整；跑马灯按实际字体宽度和可见区域动态铺满，适应窄窗口与宽屏。
- 统一窗口、侧栏导航及编辑工具栏背景，去除左右顶部的白灰分界和半透明材质色差，随浅色／深色外观切换。
- 偏好设置中的“恢复毛泽东语录”更名为“恢复语录”，保留原有恢复内容和行为。

### 标签与工具栏

- 双击文档标签栏的空白区域即可新建文档，保留已有标签的选择、关闭和拖动操作。
- 工具栏悬停提示显示在对应图标下方，靠近窗口边缘时自动调整水平位置。

### 发布记录

- 2026-10-26：升级至 2.6（Build 16），提供同时支持 Apple 芯片和 Intel Mac 的 Universal DMG，可将应用拖入“应用程序”安装。

## 2.5（2026-09-22）

### 工作区与编辑工具

- 新增命令面板（⌘⇧P）和快速打开文件（⌘P），可搜索命令、已打开文档、最近文件和工作区文件。
- 新增 JSONPath 查询、JSON 错误行列定位、JSON 树视图和 JSON 工具箱（格式化、压缩、排序、校验、转义/反转义）。
- 扩展行操作：合并行、删除空行，并保留复制、删除、移动、注释、缩进等操作。
- 新增空白字符显示，使用轻量标记显示空格和 Tab，不修改原文内容。
- 调整顶部命令栏布局：中间区域仅展示个性化语录，移除重复显示的分组名和文件名。
- 将 JSONPath、JSON 错误定位、JSON 工具箱、合并行、删除空行加入编辑菜单和编辑器右键菜单。
- 右上工具栏支持拖动排序、添加/移除工具并持久化配置；默认提供列模式、查询、左右分栏、Markdown 预览和命令面板，并可加入字体、字号、行间距、对齐等工具。
- 个性化语录移动到 NotepadPlus 标题右侧，支持横向跑马灯、百叶窗切换、颜色、字体、字号和速度设置。
- 合并 JSON 工具入口：折叠、格式化、删除值与 JSON 工具箱统一收纳到“JSON 工具”菜单；顶部语录改为紧凑显示，避免占用大块空白。
- 将语录接入 Mac Catalyst 原生标题栏，与 NotepadPlus 标题同一行显示；采用统一紧凑布局，不再额外占用编辑区高度。
- 隐藏详情区域多余的导航栏空带，让编辑工具栏整体上移；语录条改为弹性宽度横向铺满；默认将字体、字号、行间距、对齐工具置于右侧工具栏最前。
- 扩展标题栏语录胶囊的最小宽度，使其覆盖主编辑区；修复 Catalyst 自定义标题栏项因宽度约束过小导致语录条缩成窄条的问题。
- 标题栏语录采用独立填充项扩展到窗口两侧，避免单个自定义项超过 Catalyst 宽度上限后被隐藏。
- 语录条改为编辑区顶部的满宽紧凑条，左侧固定显示 NotepadPlus，避免跑马灯文字移动到屏外时误认为功能消失；同时修复标题栏自定义视图生命周期问题。
- 语录文字垂直居中；跑马灯改为从左向右循环，百叶窗切换改为水平、垂直居中展示。
- 将语录条移回原生窗口标题栏，不再单独占用编辑区一行；标题栏最左侧显示 NotepadPlus，语录紧随其后。
- 标题栏改为单一自适应全宽视图，移除分裂式填充项造成的中间空白；跑马灯使用连续重复轨道，窗口宽度变化时自动铺满且不会滚动到空白后提前结束。
