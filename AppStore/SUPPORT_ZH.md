# NotepadPlus 技术支持

NotepadPlus 是面向 Mac 的中文桌面文本与代码编辑器。

## 系统要求

- macOS 14 或更高版本
- 支持运行 Mac Catalyst 应用的 Mac

## 常见操作

- 打开文件：按 `⌘O`
- 保存：按 `⌘S`
- 查找：按 `⌘F`
- 打开快捷键管理：按 `⌘⌥,`
- 切换列模式：按 `⌘⌥C`，然后在编辑器中拖动选择矩形区域
- Markdown 预览：按 `⌘⇧M`
- 放大或缩小字体：按 `⌘+` 或 `⌘-`

应用访问外部文件时会显示系统文件选择器。用户需要主动选择文件或文件夹，NotepadPlus 才能读取或保存对应内容。
