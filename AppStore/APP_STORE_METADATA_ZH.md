## 应用描述

NotepadPlus 是一款面向开发者、技术人员和文字工作者的中文桌面文本与代码编辑器。它专注于高效、清晰、离线的文件编辑体验，让常用操作保持直观，同时为复杂文本处理提供专业工具。

主要功能：

• 多文档标签页、固定标签和分栏编辑  
• 文件夹工作区、文档分组、拖放排序和最近文件  
• Swift、Objective-C、C/C++、Python、JavaScript、TypeScript、HTML、CSS、JSON、Markdown、Shell、SQL、YAML 等语法高亮  
• Markdown 实时分栏预览  
• 矩形列选择，以及按列输入、复制、粘贴和删除  
• 普通文本与正则表达式查找替换  
• 大小写转换、空白清理、行排序和重复行移除  
• 可自定义快捷键及冲突检测  
• 字体、字号、自动保存、换行、缩进和外观设置  
• UTF-8、UTF-16、ISO-8859-1 编码，以及 LF、CRLF、CR 换行格式  
• 书签、跳转行、文档统计和批量保存

NotepadPlus 无需注册账号，核心编辑功能可离线使用。应用只访问用户通过系统文件选择器主动选择的文件或文件夹。

## 版本 2.7 更新说明

- Markdown 预览支持选择复制和一键复制正文，实时更新内容，并与源码双向同步滚动。
- 查找及替换框支持快捷键粘贴，修复多窗口重复执行粘贴的问题。
- “我的分组”支持多层级，右侧“…”可在当前分组下新建子分组，并支持调整上级。
- 分组层级随会话及未保存文档恢复，兼容旧版分组，删除父分组仍保留子分组及文档。

## 版本 2.6.1 更新说明

- 修复启动时不可访问文件被移出会话的问题，保留原分组与文档记录。
- 增加文件／文件夹重新授权入口，并保留已有文件访问书签。
- 分组与会话新增独立备份和旧版数据迁移保护，损坏数据恢复失败时停止覆盖原会话。
- 防止未载入文件的占位内容覆盖原文件。

## 版本 2.6 更新说明

- 完善普通、扩展及正则表达式查找替换，支持捕获组、循环查找、选中文本填入替换框、选区内处理和撤销／重做。
- 双击标签栏空白区域即可新建文档，工具栏悬停提示显示在图标下方。
- 标题栏只显示语录，优化靠左布局、窗口缩放自适应与浅色／深色背景一致性。
- 偏好设置中的恢复语录入口统一更名为“恢复语录”。
