# App Review 审核备注

NotepadPlus 是一款离线运行的 Mac Catalyst 文本与代码编辑器。

- 不需要账号或登录
- 不包含付费功能、订阅或应用内购买
- 不包含广告和第三方统计 SDK
- 不收集或上传用户文档
- 仅通过系统文件选择器访问用户主动选择的文件和文件夹
- Markdown 预览在本地完成，JavaScript 已禁用

## 建议审核步骤

1. 启动应用，按 `⌘N` 新建文档并输入文本。
2. 按 `⌘S`，在系统面板中选择位置并保存文件。
3. 按 `⌘F` 打开查找替换，可启用“正则表达式”。
4. 按 `⌘⇧M` 打开 Markdown 分栏预览。
5. 按 `⌘⌥C` 切换列模式，在多行文本中拖动形成矩形选择，然后输入、粘贴或删除。
6. 打开“偏好设置 → 快捷键”，可修改快捷键并查看冲突提示。
7. 使用工具栏的文件夹按钮选择文件夹，可测试工作区和文件内查找。
